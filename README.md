# Code Galaxy Portfolio

The personal portfolio of Shakil Ahamed, an Information Technology student and aspiring full-stack developer interested in Angular, modern web development, Python automation, artificial intelligence, IoT, and mobile applications.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Deploy on Netlify

1. In Netlify, choose **Add new project** and **Import an existing project**.
2. Select GitHub and choose this repository.
3. Netlify will detect Next.js automatically.
4. Confirm the build command `npm run build` and publish directory `.next`.
5. Select **Deploy**.

The included `netlify.toml` supplies these settings automatically.
